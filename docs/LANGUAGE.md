# Battle Bot Assembly — Language Reference

> Generated by `node tools/build.js` from `js/core/isa.js`. The same tables drive the assembler, the VM and the in-app reference.

## Program structure

- Line 1 of a robot file is the robot's name. The program starts on line 2.
- Comments start with ; or #. Mnemonics, registers, labels and constants are case-insensitive.
- Labels end with a colon (`loop:`) and may share a line with an instruction.
- Constants: `.def NAME value`. They can be used anywhere a number is allowed, including memory offsets.
- Numbers are decimal (`-12`) or hexadecimal (`0x1F`). All values are 32-bit signed integers.
- Registers R0..R7 start at 0. Memory has 256 words ([0]..[255]), addressed as `[12]`, `[R1]` or `[R1+4]`.
- When execution runs past the last instruction it wraps to the first, so a program is an implicit loop.
- Each robot gets 50 cycles per tick. Most instructions cost 1 cycle; SCAN and RADAR cost 3. An infinite loop only uses up its own robot's budget.
- Angles: 0° points right (east), 90° points down (south), increasing clockwise. Positions use screen coordinates with (0,0) at the top-left.
- Runtime errors such as division by zero or a stack overflow fault the robot. Its CPU stops and the robot keeps drifting with its last orders. Other robots are unaffected.

```asm
MyBot            ; line 1: the robot name
.def RANGE 150   ; constant
loop:
    SCAN 20
    GET  R0, SCAN_DIST
    CMP  R0, 0
    JL   loop
    FIRE
    WAIT
    JMP  loop
```

## Operands

| Kind | Accepts |
|---|---|
| `dst` | register `R0`..`R7` or memory `[n]`, `[Rx]`, `[Rx+n]`, `[Rx-n]` |
| `src` | anything `dst` accepts, plus a number or `.def` constant |
| `target` | a label |
| `sensor` | a sensor name (see below) |

## Instructions


### Data

| Instruction | Cycles | Description | Example |
|---|---|---|---|
| `MOV dst, src` | 1 | dst = src | `MOV R0, [R1+2]` |
| `PUSH src` | 1 | Push value onto the stack (max 64 entries). | `PUSH R3` |
| `POP dst` | 1 | Pop the top of the stack into dst. | `POP R3` |

### Arithmetic

| Instruction | Cycles | Description | Example |
|---|---|---|---|
| `ADD dst, src` | 1 | dst = dst + src | `ADD R0, 5` |
| `SUB dst, src` | 1 | dst = dst - src | `SUB R0, R1` |
| `MUL dst, src` | 1 | dst = dst * src | `MUL R0, 3` |
| `DIV dst, src` | 1 | dst = dst / src, truncated toward zero. Division by zero faults. | `DIV R0, 2` |
| `MOD dst, src` | 1 | dst = dst mod src. Result takes the sign of src, so MOD R0, 360 always gives 0..359. | `MOD R0, 360` |
| `INC dst` | 1 | dst = dst + 1 | `INC R2` |
| `DEC dst` | 1 | dst = dst - 1 | `DEC R2` |
| `NEG dst` | 1 | dst = -dst | `NEG R1` |
| `ABS dst` | 1 | dst = \|dst\| | `ABS R1` |
| `MIN dst, src` | 1 | dst = min(dst, src) | `MIN R0, 45` |
| `MAX dst, src` | 1 | dst = max(dst, src) | `MAX R0, -45` |
| `AND dst, src` | 1 | Bitwise AND | `AND R0, 1` |
| `OR dst, src` | 1 | Bitwise OR | `OR R0, 4` |
| `XOR dst, src` | 1 | Bitwise XOR | `XOR R0, R0` |
| `RAND dst, src` | 1 | dst = random integer in 0..src-1 (src must be > 0). Deterministic per match seed. | `RAND R0, 360` |

### Math

| Instruction | Cycles | Description | Example |
|---|---|---|---|
| `ATAN2 dst, src, src` | 1 | dst = angle of vector (dx = 3rd, dy = 2nd) in degrees 0..359, using the arena angle convention. | `ATAN2 R0, R2, R1` |
| `SIN dst, src` | 1 | dst = round(sin(src degrees) * 1000) | `SIN R1, R0` |
| `COS dst, src` | 1 | dst = round(cos(src degrees) * 1000) | `COS R1, R0` |
| `SQRT dst, src` | 1 | dst = floor(sqrt(src)). Negative input faults. | `SQRT R0, R0` |
| `NORM dst` | 1 | Wrap an angle into -180..179. Turns "target - current" into the shortest signed turn. | `NORM R0` |

### Flow

| Instruction | Cycles | Description | Example |
|---|---|---|---|
| `CMP src, src` | 1 | Compare a with b and remember the result for the next conditional jump. | `CMP R0, 100` |
| `JMP target` | 1 | Jump unconditionally. | `JMP loop` |
| `JE target` | 1 | Jump if a == b (last CMP). | `JE found` |
| `JNE target` | 1 | Jump if a != b. | `JNE again` |
| `JL target` | 1 | Jump if a < b. | `JL too_close` |
| `JLE target` | 1 | Jump if a <= b. | `JLE ready` |
| `JG target` | 1 | Jump if a > b. | `JG far` |
| `JGE target` | 1 | Jump if a >= b. | `JGE far` |
| `CALL target` | 1 | Push the return address and jump to a subroutine. | `CALL dodge` |
| `RET` | 1 | Return from a subroutine (pops the return address). | `RET` |
| `NOP` | 1 | Do nothing (costs one cycle). | `NOP` |
| `WAIT` | 1 | End this robot's turn for the current tick. Unused cycles are lost. | `WAIT` |
| `HALT` | 1 | Stop the program permanently. The robot keeps its last speed and heading. | `HALT` |

### Robot

| Instruction | Cycles | Description | Example |
|---|---|---|---|
| `GET dst, sensor` | 1 | Read a sensor value into dst (see the sensor table). | `GET R0, HEALTH` |
| `SPEED src` | 1 | Set the desired speed (-3..5 units/tick, clamped). The robot accelerates at 0.5 per tick. | `SPEED 5` |
| `TURN src` | 1 | Set the desired heading to current heading + src degrees. The body turns at most 8°/tick. | `TURN -90` |
| `HEAD src` | 1 | Set the desired absolute heading in degrees. The body turns at most 8°/tick. | `HEAD 180` |
| `AIM src` | 1 | Set the desired absolute turret angle. The turret turns at most 20°/tick, independently of the body. | `AIM R1` |
| `FIRE` | 1 | Fire along the turret at the end of this tick if COOLDOWN is 0. Otherwise nothing happens. | `FIRE` |
| `SCAN src` | 3 | Look for the nearest enemy inside a cone of src degrees (1..90) centred on the turret. Obstacles block the view. Updates the SCAN_* sensors; SCAN_DIST is -1 if nothing is found. | `SCAN 20` |
| `RADAR` | 3 | Find the nearest enemy projectile within 250 units that is approaching you. Updates the THREAT_* sensors; THREAT_DIST is -1 if none. | `RADAR` |

## Sensors (read with `GET dst, SENSOR`)

| Sensor | Meaning |
|---|---|
| `X` | Your x position (0 = left edge). |
| `Y` | Your y position (0 = top edge). |
| `HEADING` | Your current body heading, 0..359. |
| `SPEED` | Your current speed (rounded). |
| `HEALTH` | Remaining health, 0..100. |
| `COOLDOWN` | Ticks until you can fire again (0 = ready). |
| `TURRET` | Your current turret angle, 0..359. |
| `SCAN_DIST` | Distance to the enemy found by the last SCAN, or -1. |
| `SCAN_ANGLE` | Absolute angle from you to that enemy. |
| `SCAN_X` | That enemy's x position. |
| `SCAN_Y` | That enemy's y position. |
| `SCAN_HEADING` | That enemy's heading (use it to lead your shots). |
| `SCAN_SPEED` | That enemy's speed. |
| `THREAT_DIST` | Distance to the projectile found by the last RADAR, or -1. |
| `THREAT_ANGLE` | Absolute angle from you to that projectile. |
| `THREAT_HEADING` | Direction that projectile is travelling. |
| `FRONT` | Free distance ahead of your body (to a wall or obstacle) along your heading. |
| `LAST_HIT` | Ticks since you were last hit by a projectile, or -1 if never. |
| `TICK` | Current simulation tick. |
| `ENEMIES` | Number of enemy robots still alive. |
| `ARENA_W` | Arena width (800). |
| `ARENA_H` | Arena height (600). |
